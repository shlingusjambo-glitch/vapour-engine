# Vapour Alpha 0.2 acceptance project

This project uses public engine APIs only. It combines procedural terrain with
a matching native collider, dynamic Rapier physics, collision callbacks, live
audio pitch, glTF import, TypeScript and Vapour Script in one module graph,
action-based wheel input, and retained UI on the engine's screen overlay.

```sh
pnpm vapour validate examples/alpha-0.2-acceptance
pnpm vapour build examples/alpha-0.2-acceptance
pnpm vapour dev examples/alpha-0.2-acceptance --port 4175
```

Use the arrow keys to orbit and the mouse wheel to zoom.
