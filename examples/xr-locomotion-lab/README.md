# Vapour XR Locomotion Lab

Quest-oriented Alpha 0.2.1 acceptance project using public Vapour APIs. It
exercises WebXR tracking, profiles/haptics, swept hand contacts, surface slip,
arm locomotion, Rust/Rapier queries, WebGPU materials, spatial audio, and clear
runtime diagnostics. It never treats successful tracking as proof that stereo
WebGPU presentation is complete.
